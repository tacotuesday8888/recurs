# Fresh product comparison

Declared before any model run. These are three new authored tasks, separate from
all previous Recurs benchmarks. The question is whether Recurs's coordinated
workflow helps complete practical, bounded coding work.

| Task | Acceptance |
| --- | --- |
| `shipment_quote` v1 | Complete cart validation, discounts, parcel rates and quotation across four modules. |
| `incremental_build_repair` v1 | Repair snapshot changes, reverse dependencies and rebuild selection across three modules. |
| `release_window_regressions` v1 | Write a checker that accepts conforming scheduler APIs and rejects three seeded behavioral regressions. |

Use each task's frozen README, visible tests, external hidden checks, allowed
paths and fixture hash. No old tasks or results count toward this campaign.
Both products receive the same objective and byte-identical fixture. Hidden
checks and reference solutions are never placed in the model workspace. These
are public authored tasks, not contamination-resistant third-party benchmarks.

## Frozen comparison

- Native official Codex CLI 0.145.0, Luna medium, against Recurs balanced teams:
  Luna medium parent/reviewer and Terra medium implementer/repair workers.
  Both use the same saved Codex subscription account. No API key, credit
  purchase, or change to Recurs provider execution guards.
- Two repetitions per task: Codex, Recurs, Recurs, Codex. Tasks run in the table
  order. Twelve planned slots total. Retain every outcome; no favorable-result
  selection or outcome-based retries.
- Five minutes per slot, including fixture setup and grading. A one-hour outer
  campaign deadline stops any remaining work. Setup and source reviews can happen
  before/after that deadline without model requests.
- Record actual executed bundle hash, source commit, Codex binary hash, Node
  version, fixture/blueprint authority, campaign IDs and every declared slot in
  `declaration.json` before launching models.
- Recurs uses its existing user-invoked `benchmark company` protocol with an
  explicit `--control codex`. Generic `recurs run` remains scripted and is not
  used. Native Codex runs `exec --json --ephemeral --ignore-user-config` with
  workspace-write sandbox, approval policy never and forced ChatGPT login.
  Plugins/hooks/apps, configured MCP servers and web search are disabled for the
  native control; native coding and delegation tools remain available. Native
  skill discovery may differ from Recurs; inspect retained native events and
  disclose any external skill access. Do not imply hermetic skill isolation.
- Verify every saved model/effort/account route before the first model request.
  Stop after setup failure or invalid native execution, retain the record, and
  do not silently restart. A normal incorrect candidate remains a measured
  outcome. All slots still appear in the audit, including unstarted slots.

## Scoring and presentation

A completed task requires completed execution, passing workspace integrity,
visible and hidden checks, and source review against the published task rules.
A timed-out process with passing files is shown as timed out with a passing
candidate, not a completed task. Source review rejects grader introspection,
fixture-oracle imports, global tampering, invalid contract inputs and persistent
call-count tricks equally for both products. Record any audit decision.

Lead with completed tasks out of attempts and each attempt's elapsed time. Time
runs from adapter entry to the end of execution/grading, before optional artifact
retention. It includes setup and review/repair in Recurs. Show timeouts and failed
attempts; label any successful-only summary. No universal ranking, invented
productivity score or raw hidden-check count as units of work.

Tokens are provider-reported counters. Input includes cached input; do not add
cached tokens again. Do not assume missing counters are zero. Audit native
subagent usage coverage before asserting equal token accounting. Runtime request
counts represent adapter invocations and are not comparable vendor model-call
counts. Codex subscription does not provide per-task dollar bills: dollar cost
and savings stay unknown. This compares complete configurations, including
worker models, tools and orchestration; it does not isolate any one factor.

The scheduler task covers end exclusivity, paused eligibility and priority
ordering. It measures seeded regression-check effectiveness, not general bug
finding. Two repeats across three small tasks are descriptive evidence only.
