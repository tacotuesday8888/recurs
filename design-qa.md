# Terminal acceptance

The previous V19 company-floor direction is retired. Current acceptance uses
real workflows through the terminal, recorded in [release readiness](docs/RELEASE_READINESS.md).

Verify input, paste, completion, streaming Markdown, code, long output,
scrolling, drafts and queued approvals. Exercise the team tree separately from
actual execution history, exact child inspection, cancellation and reopening.
Test small windows and resizing, no-color and failures. A static screenshot
alone does not establish acceptance.
